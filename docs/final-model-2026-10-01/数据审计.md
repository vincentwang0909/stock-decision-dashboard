# 数据、缺失与数值审计

这是 2026-10-01 行情／2026-10-02 交付的历史验证材料。当前模型以 [2026-10-04 指标模型](../indicator-model-2026-10-04.md)、AGENTS.md 和现行配置为准；以下版本、参数与结论保留其原有日期。

证据分别是历史保存快照、旧本地 22 只缓存、新实际 29 只 watchlist 全量抓取、六类证券的源数据抽样。它们的 universe/as-of 不同，缺失数量表不能直接当作同日预测准确率提升。历史没有原始 OHLCV；新数据验证不能回写成历史原点的新输入。

## 字段清单与合法缺失

详细字段清单按 ticker×horizon×interval×字段记录数值、正常 false/0、缺失/依赖不可用/历史不足/不适用、bars/observations、source/as-of、实际方法/价格基础/币种。汇总保留在 [current-data/field-summary.json](current-data/field-summary.json) 和 [previous-data/field-summary.json](previous-data/field-summary.json)。2026-10-04 已核对两份完整清单与复现包内容的 SHA-256 一致，再删除仓库中的重复副本；完整清单在外部包的 `fields/current-data.csv` 和 `fields/previous-data.csv`，位置见 [离线复现说明](离线复现.md)。

ATR 百分位比较 ATR14/该根 close×100，最近 W 个**有效** ATR% 观测包含当前值、用 <= ties。ATR14 采用 Wilder，首 TR=H−L，13 根 warm-up：60/120/250 至少 73/133/263 bars，最低数量不等于完整收敛保证。不复用 120 填 250，也不缩短种子回看换内存。核心 ATR14/60 可用而可选 250 缺失，不把整只证券或核心质量判成完全缺失。

历史 CSV Short：ATR60 940/940、120 919/940、250 0/940；Mid 为 913/884/884，Long 为 856/0/0。Short 最多 240 个原生 4H bars，Long 最多 105 周；这足以解释历史 250/长周线窗口缺失。

KDJ 保留 RSV9、K/D 初值50、2/3+1/3递推、J=3K−2D、J≥80/J≤20；J 不裁剪。函数需要 period+3=12 bars，元数据已从9修正到12。触发/未触发/不可用三态分开，false 不再显示破折号；Long 不配置 KDJ，因此不适用。历史三种已配置 KDJ 的各 940 行旗标均存在，主要问题是显示语义。测试覆盖11/12 bars、正常false/0及极端J。

## 真实历史与源能力

新默认 Daily=10y、1H=120d、native4H=365d，分别有 2,800/6,000 bars 的保留上限。10y 是足够长的真实种子；后续 Daily/native4H 使用有限1mo重叠，已完成重叠 OHLCV 任一字段发生变化则回到完整有界种子抓取，以避免 split/调整后混合旧基础。冷启动/IPO/源失败不能保证最大窗口有足够返回值。

六类样本 NVDA、FFAI、CRCL、QQQ、SOXL、SQQQ，24 次本地 yfinance 1.5.2 请求均实际返回。**上游公开 interval 列表未列4h，但此次本地源真实返回 dataGranularity=4h**；没有把旧 metadata 当作能力证明，没有从1H重采样。通常365d返回725根、剔除2个缺失交易段后723；CRCL返回661/有效659。原120d返回240，与365d重叠 OHLCV 无差异。此能力尚未在部署后的 Render 依赖中验证；若源今后不返回原生4H，保持 unavailable 和原因，不能静默改方法。参见 [provider-audit.json](provider-audit.json)、[native-session-audit.json](native-session-audit.json)。

请求标签不是返回长度证明：1H120d抽样返回840根/120 sessions，约171自然日；Daily返回first/last与实际数目单列。NVDA/QQQ/SOXL/SQQQ Daily2513，FFAI1527，CRCL333。每份 provenance 保存 request period/interval/method、实际first/last、有效bars、as-of/来源与调整基础；HTTP原始参数/响应哈希在 [raw-source-audit.json](raw-source-audit.json)。

能力审计里的 `history_metadata` 是 yfinance 的可触发额外请求的属性；Daily 抽样该属性出现 `1h` 时不能当成同次 Daily 请求的 granularity 证明。另存的原始 Daily HTTP 响应为 `1d`，并逐字段与 Daily 序列化对应；原生4H的判断使用实际4H返回和交易时段校验，不依赖这项 Daily 属性。

原生4H按XNYS calendar验证09:30/13:30，正常最后段是150分钟，半日通常210分钟；它们作为明确 provider-native regular-session tail，**不叫完整四小时**。Jan30上午-only、Feb2下午-only的异常完整日样本被剔除。未完成bar可用于当前指标，带 completed=false；已确认 pivots 排除它。完成周线要求该周所有预期exchange sessions都有Daily且最后session已收盘，避免周五盘中误用、Good Friday漏掉已完成周、起始残周或缺日误当完整周。

## 入口、时点、单位与价格基础

整行校验 Open/High/Low/Close/Volume 和 timestamp；价格正且Low≤Open/Close≤High、Volume≥0、严格时间顺序、不重复。缺 Open/Volume 不补0，各数组不分别筛选；坏行/原因保留，停牌/不足不插值。拒绝无时区的intraday时间、无效日期和非有限值；实际0/false保留。美国Daily日期须为交易日，native4H错序在排序之前拒绝。

Regular quote、previous close、Daily close、postmarket来源各自注明。抽样regular quote与Daily close差值为浮点精度量级，部分native4H最后close与regular/Daily确有差异（如NVDA230.96对230.86）。同供应商响应→序列化一致并不证明跨端点 corporate-action 基础或真实市场价已独立认证。当前记录 `auto_adjust=False` 和 `unverified_cross_endpoint`，不会把不同端点价格无条件拼接成认证结果。增量重叠校验发现调整差异就重建种子；历史FFAI原始bars缺失，不能断言其旧错误来自split。

SPY/QQQ RS比较同日期观测；错时的已记录基准保持unavailable。市场每字段保存source/as-of/单位；10Y收益率是百分数，变化为bps，VIX是指数点，指数变化是百分数；真实`us_10y`字段已接到模型，缺失市场不标normal。每日共用宏观观测不当作多证券独立证据。

## 数值约定与独立核对

| 指标 | 当前约定 |
|---|---|
| SMA/EMA/数值斜率 | SMA末P根均值；EMA首P根SMA种子后α=2/(P+1)；斜率跨度 min(5,max(1,floor(P/4)))，保留原始数值精度 |
| RSI6/14/21 | 前P个price deltas种子，Wilder gain/loss；零loss返回100的既有约定保留 |
| MACD12/26/9 | 各EMA同种子；signal沿用项目对早期缺MACD填0的种子规则，未无差别改成其他库；柱=line−signal，1/3/5根变化；最近交叉带年龄/时间，不冒充本根交叉 |
| ADX/DI14 | 项目滚动均值TR/DM和DX组合；不是标准库任意Wilder ADX。零区间不可用，不产生NaN/方向信号 |
| ATR14及百分位 | Wilder；首TR=H−L；percentile用ATR%、最近有效观测、<=、包含当前 |
| Bollinger20×2 | 最近20、总体标准差ddof=0；width与%B保持原参数 |
| KDJ9 | RSV9；K/D=50种子；2/3递推；J不裁剪；12 bars含斜率需求 |
| OBV/RVOL | OBV首根0，同价不变；RVOL当日量/包含当前的5/20/60均量；零均量为unavailable |
| RS | 本证券20/60/120根return减同as-of SPY/QQQ return；不新增基准 |
| Fib | confirmed pivot严格局部极值；Short4H(80,3,8,4%)，MidDaily(100,4,10,10%)，Long完成Weekly(104,2,5,15%)；独立来源/哈希/derivation，命名fallback保留 |
