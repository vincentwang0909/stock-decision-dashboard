`--live-provider` 会进行一次真实完整 watchlist 抓取，应另存结果并注明新的行情日期、供应商状态和输入变化；不能把它与上述冻结输入互算减幅。实际部署容器的 cgroup/file cache/0.5 CPU 检查仍见 [内存与运维](内存与运维.md)。

重新生成 940 个时点输入时，原 CSV 路径和 SHA-256 见 [输入回执](replay-input-receipt.json)。`prepare-final-replay.py` 可读取归档 `replay/original-replay.json`，保留六条历史原码不一致标记。原码脚本在归档 `original-v2-source/scripts/replay-history.js`；它需要 CSV 转成的 JSON 数组，归档不重复保存这一大数组。已有原码结果是核对证据，不是生产决策输入。

完整回滚可以从已保留的起始 Git commit 恢复源码；归档源码不包含 `.git` 或生产持久数据。当前修改没有自动提交；回滚前应自行保存工作区以及持久 watchlist/profile/历史数据库。关闭 `shortV2.enabled` 只回退股票 Short 分支，不能撤销其他修复。0.995 采用失败开关保持关闭。
